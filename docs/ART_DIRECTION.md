# SKYTOPIA · 하늘의 예술

## 방향

밝은 하늘 위에서 자연과 공학이 공존하는 작은 문명. 흰 건물, 청색 지붕, 황동 구조, 청록 에테르가 핵심이다. 실루엣은 원거리에서도 주택·농업·공업·동력 시설을 구별해야 한다. 상용 게임의 모델·로고·캐릭터를 복제하지 않는다.

| 역할             | 색                |
| ---------------- | ----------------- |
| 하늘 / 구름      | #87CEEB / #F3F7FF |
| 식생 / 건축 외벽 | #75AD7D / #E4EAF0 |
| 금속 / 에테르    | #52677C / #35D5FF |
| 황동 / 산업      | #E8BC67 / #A98A69 |
| 밤 / 위험        | #172A48 / #E45B52 |

중앙 정의는 `src/scene/art.ts`. 게임 규칙의 Kind·질량·칸·수용량을 이 파일에서 결정하지 않는다. 기존 분석 오버레이의 위험 색과 아이콘을 우선한다.

## 건물과 섬

주택은 청색 지붕·발코니·흰 벽, 산업은 굴뚝·금속 지붕·가동 표시, 농업은 재배 줄·관개·온실로 구별한다. 발광은 가동·전력·입주·밤 상태를 따른다. 모델의 기본 높이는 PHYSICAL, 업그레이드 높이는 기존 facility 규칙을 따른다. 새 장식 때문에 실제 충돌 칸을 늘리지 않는다.

섬 암석은 살아 있는 지상 플랫폼에서 생성한다. 플랫폼 삭제 후 남은 절벽이 건축 가능한 땅으로 보이지 않아야 한다. 에테르 광맥과 폭포는 장식이며 자원 생산이나 부양력을 추가하지 않는다.

## 빛과 환경

단일 방향광·반구광·안개와 하늘 그라데이션을 사용한다. 일출과 저녁은 따뜻한 수평선, 밤은 남색·별·달. 세계 지역은 기존 region ID로 색을 선택한다. 구름은 저렴한 인스턴스 기하이며 볼륨 렌더링이라고 부르지 않는다.

## UI·브랜드

직접 만든 SVG 마크는 떠 있는 섬, 도시, 중심 결정의 조합이다. 시스템 글꼴을 사용한다. 기존 메뉴·HUD·지도·캠페인·인물의 정보 구조와 접근성 이름을 유지한다. 모든 새 설정은 한국어와 영어를 제공한다. 캡처 로고는 선택 사항이다.

## 범위

실제 게임 화면의 절차형 모델을 개선한다. 사진 프리셋은 표시만 바꾼다. 블룸·SSAO·DOF·볼류메트릭 구름·상용 텍스처 팩은 현재 구현했다고 주장하지 않는다. Phase 11–13의 전투·MMO·결제 시스템은 포함하지 않는다.
