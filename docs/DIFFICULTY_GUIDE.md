# 난이도와 보조 기능

난이도 수치는 기존 규칙을 유지한다. 초기 캠페인별 고정 자원·블록·해금과 별도 미션 규칙이 우선한다. 조작 보조와 그래픽은 난이도에 합산되지 않는다.

| 규칙                | 쉬움 easy | 보통 normal | 어려움 hard |
| ------------------- | --------- | ----------- | ----------- |
| 구조 강도           | 1.3       | 1           | 0.85        |
| 구조 손상           | 0.65      | 1           | 1.25        |
| 구조 기본 유예(초)  | 30        | 20          | 12          |
| 수리/보강 비용 배율 | 0.7       | 1           | 1.3         |
| 도시 노동 가능 비율 | 70%       | 60%         | 55%         |
| 식량 소비 배율      | 0.8       | 1           | 1.15        |
| 운영 유지비 배율    | 0.75      | 1           | 1.15        |
| 도시 초기 유예(초)  | 80        | 60          | 40          |
| 구호 횟수           | 3         | 1           | 0           |
| 기본 크레딧         | 650       | 500         | 300         |
| 재난 예보 배율      | 1.4       | 1           | 0.75        |

기본 블록 타이머는 20초다. 낙하를 사용하는 캠페인은 쉬움 0.5배·보통1배·어려움1.25배 속도이며 구조 위기 감속과 개별 세계 설정이 별도로 작동한다. 모든 모드를 30/20/12초로 일괄 교체하지 않았다.

기본 재난 예보90초·활동40초·회복120초를 유지한다. 미션·실험·세계 빈도·연구가 명시적으로 덮어쓸 수 있다. 생존 웨이브는 기존 성장 목표·보상 수령·회복 구간과 최대 강도5를 유지한다.

설정의 안내형/일반형/전문가형, 키 반복, 카메라 감도, 큰 글자·높은 대비·모션 감소는 독립적인 도움이다. 무료 자원은 자유 건설의 편안한 프리셋과 실험실에 한정된다. 온라인은 서버 고정 규칙으로 시작하고 개인 난이도·오프라인 공급 보정을 쓰지 않는다.
