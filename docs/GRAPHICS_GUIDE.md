# 그래픽과 사진 설정

설정 → 그래픽에서 화질을 선택한다. 기본은 MEDIUM이다. 이전 저장은 graphicsVersion=1, medium, 구름 밀도 0.7 기본값을 받으며 기존 그림자·시민·차량·접근성 선호는 유지한다. 화질을 직접 선택하면 아래 개별 예산이 적용된다.

| 설정             | LOW   | MEDIUM  | HIGH    | ULTRA   |
| ---------------- | ----- | ------- | ------- | ------- |
| 최대 DPR         | 1     | 1.6     | 2       | 2       |
| 그림자 맵        | 꺼짐  | 1024    | 2048    | 4096    |
| 구름 덩어리 상한 | 6     | 12      | 20      | 28      |
| 시민 / 차량 상한 | 8 / 4 | 32 / 12 | 48 / 16 | 48 / 16 |
| 재난 입자 상한   | 24    | 96      | 160     | 200     |
| 광맥·폭포        | 꺼짐  | 켜짐    | 켜짐    | 켜짐    |

시민·차량은 실제 인구·연결된 경로·생산 가동 조건에도 제한된다. 이 수는 화면 표현 예산이며 실제 인구나 운송량이 아니다. 기존 모션 감소·섬광 감소·카메라 흔들림 설정은 화질 변경으로 초기화하지 않는다. 렌더링 속도가 낮으면 LOW와 구름 밀도를 먼저 낮춘다.

주요 건물은 LOW 또는 원거리에서 실루엣 모델로 단순화한다. 구조물을 선택하면 상세 표현을 유지한다. 반복 동력 시설은 상태별 정적 템플릿을 공유하고 중심 코어는 실제 출력에 따라 회전한다.

## 사진

상단 사진 모드에서 실제 환경, 일출, 맑은 낮, 황금빛 저녁, 밤, 시네마틱, 설계도를 선택한다. 시간대와 구름은 화면 표현이며 실제 재난·자원·경기 시간은 바꾸지 않는다. 실제 재난 이펙트는 보존한다. 시네마틱은 따뜻한 조명 프리셋이며 DOF 후처리가 아니다.

싱글플레이는 일시 정지한다. 온라인은 서버 시계가 계속 흐른다. HUD·고스트·분석 표시는 숨긴다. 마우스 오른쪽 드래그로 회전하고 휠로 확대한다. Escape로 돌아간다.

PNG는 1× 또는 2×, 긴 변 최대 3840px로 저장한다. 저장 요청 동안만 렌더 크기를 올린 뒤 즉시 원래 크기로 복구한다. 상시 preserveDrawingBuffer를 사용하지 않는다. 로고는 선택 사항이며 저장 성공·실패를 표시한다. 사진 프리셋은 저장 파일이나 온라인 명령에 포함하지 않는다.

## 성능 해석

검증 자료는 docs/verification/phase10-before.json과 변경 후 자료를 참조한다. Windows Chrome SwiftShader, 1440×900, DPR 1, 개발 빌드와 활성 경제 시뮬레이션 조건이다. 소프트웨어 렌더링의 FPS를 실제 GPU 결과로 해석하지 않는다. 드로우 콜·삼각형·geometry·texture 수와 복귀 후 자원 수도 함께 본다. GC·CPU 부하·표본 수 차이 때문에 단일 측정의 향상률은 보장치가 아니다.
