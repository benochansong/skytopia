# Phase 10 시작 점검

Phase 9 커밋 19627b1을 기준으로 시작했다. 실제 Phase 1–9 게임·30개 캠페인·수직 구조·재난·세계 운송·게스트 온라인 서버가 존재한다. Phase 8 PR #7과 Phase 9 PR #8은 draft이며 공개 배포하지 않았다.

## 관찰

- 섬은 고정 원뿔과 13개 암석이어서 실제 플랫폼 외곽과 관계가 약하다.
- 코어는 기본 출력 1로 그려져 손상이 발광에 반영되지 않는다.
- 반복 건물의 창문은 템플릿 기본값 때문에 전력과 관계없이 발광한다.
- 주택·공장·농장은 구별되지만 공통 흰색·금색·에테르 재질 체계가 없다.
- 동일 재질 장식마다 별도 instanced draw call이 생긴다. 농장의 작물 12개도 각각 호출한다.
- 하늘은 평면 색이며 지역별 환경은 캠페인 일부만 반영한다.
- 화질은 개별 옵션뿐이다. 사진 모드는 기본 PNG만 지원한다.

## 우선순위

프롬프트 마지막 우선순위에 따라 섬, 코어, 주요 건물, 배치 미리보기, 조명과 사진을 먼저 완성한다. 렌더링 정의를 게임 규칙에서 분리하고, 기존 저장·한국어/영어·온라인 권위를 보존한다. 공유 재질과 템플릿 병합으로 장식 증가의 비용을 제한한다. 후처리·상용 외부 에셋·새 경제 시스템은 필요성을 입증하지 않고 추가하지 않는다.
