# PHASE 10 — VISUAL UPGRADE 개발 보고

## 1. Phase 1–9 실제 상태

기존 3D 건축, 구조 붕괴, 도시 경제, 30개 캠페인, 다층, 재난, 세계 운송, 게스트 2인 온라인과 Phase 9 조작 개선 위에서 작업했다. Phase 9 PR #8은 전체 GitHub CI를 통과했다. 이번 단계는 별도 브랜치이며 이전 단계의 초안을 병합하지 않았다.

## 2. 이전 화면의 문제

고정 섬 암석, 항상 정상으로 빛나는 코어와 반복 건물, 평면 하늘, 재질별 병합 없는 장식, 기본 PNG만 있던 사진 모드를 확인했다. 진단은 PHASE10-AUDIT.md에 있다.

## 3. 아트 방향

흰 건축·청색 지붕·금색 공학·청록 에테르·녹색 자연의 팔레트를 중앙화했다. 자세한 규격은 ART_DIRECTION.md. 유료·상용 게임 에셋을 사용하지 않았다.

## 4. 공중섬

현재 지상 플랫폼을 따라 암석과 광맥을 인스턴싱한다. 삭제된 타일 아래 장식도 사라진다. 내부 암석은 중심에서 더 깊고 외곽은 얕게 구성한다. 금속 플랫폼은 기존 공학 지지대를 유지한다. 나무도 지지하는 실제 플랫폼이 있을 때만 그린다.

## 5. 에테르 코어

흰 기단·황동 고리·청록 결정을 사용한다. 실제 코어 내구도로 발광과 회전 출력이 줄어든다. 별도의 부양력이나 자원을 만들지 않는다. 시설의 정지·효율은 발전기와 부양기 표현에도 반영한다.

## 6. 주거 건물

기본·대형 주택·아파트·주거단지에 높이별 발코니, 금색 처마, 청색 지붕과 화단을 추가했다. 입주·전력·가동·밤 조건을 만족해야 창문이 빛난다. 업그레이드 장식은 실제 레벨에 따른다.

## 7. 산업 건물

공장·작업장·제조소·정제소에 산업색 몸체, 두 굴뚝, 금속 작업문과 가동 표시를 사용한다. 가동하지 않는 시설의 표시등이 켜지지 않도록 기존 템플릿 기본값 문제를 수정했다.

## 8. 전력·부양 시설

기존 시설별 모양과 실제 출력 연결을 보존하고 코어 계열 재질을 정리했다. 부양 분사와 발광은 기존 구조 분석의 factor에 따른 가동 여부를 따른다. 반복 동력 시설은 정적 템플릿을 공유하고 중심 코어만 계속 회전한다. 모든 동력 시설을 신규 외부 모델로 교체한 것은 아니다.

## 9. 농업·공원

농장·온실·수경 농장에 재배 줄, 관개 줄, 유리색 지붕을 구분한다. 공원의 기존 나무·벤치·산책로는 유지한다. 성장은 실제 생산량을 바꾸지 않는 장식이다.

## 10. 플랫폼과 구조

실제 플랫폼 종류·보강·다층 구조를 유지한다. 암석과 금속의 표면 구별, 분석 응력 색은 기존 규칙을 따른다. 새 건물은 PHYSICAL 높이와 facility 업그레이드 배율을 사용한다. 시각 크기가 점유 판정을 결정하지 않는다.

## 11. 다리·엘리베이터

기존 실제 끝점 기반 다리·트러스·기둥과 전력 조건을 따르는 엘리베이터를 보존한다. 이번 단계에서 모든 구조물의 모양을 새로 만들지 않았다. 가짜 연결이나 장식용 운송 용량을 추가하지 않았다.

## 12. 시민·차량

한 상자 대신 머리·몸·다리, 차체·운전석·바퀴를 하나의 공유 geometry로 병합했다. 기존 실제 경로·인구·가동 조건, 인스턴스 상한과 모션 감소 설정을 그대로 따른다.

## 13. 비행선

기존 일곱 선종과 실제 trip 진행률·출발·도착 상태를 유지한다. 도시 주변 장식 비행선은 실제 무역으로 집계하지 않는다. 선박 모델 전면 교체와 새로운 프로펠러 애니메이션은 이번 우선 구현에 포함하지 않았다.

## 14. 항구

기존 등급별 부두·크레인·표시와 실제 항구 기반 선박 위치를 보존한다. 부두가 없는 도시에서 가짜 교역선이 정기 운항하는 연출을 추가하지 않았다.

## 15. 하늘·구름

하늘 구체의 그라데이션, 세 높이의 인스턴스 구름과 밀도 설정을 추가했다. 구름은 하나의 instanced draw call로 묶인다. 실제 기상 구름량은 조명과 안개 색에 반영한다. 볼륨 구름은 구현하지 않았다.

## 16. 폭포·자연

현재 외곽의 실제 앵커 플랫폼에서만 얇은 폭포 리본을 그린다. LOW에서는 광맥·폭포를 생략한다. 식생과 폭포는 시각 효과이며 경제에 영향을 주지 않는다.

## 17. 조명

낮·일출·저녁·밤의 방향광 색, 반구광, 안개와 하늘을 조정했다. 그림자 맵 크기는 화질별 예산을 따른다. 블룸·SSAO·DOF는 성능 비용을 피하기 위해 추가하지 않았다.

## 18. 낮과 밤

실제 도시 dayTime을 사용하고 밤에는 별과 달을 표시한다. 사진 시간대는 별도 임시 상태이며 게임 시간은 바뀌지 않는다. 창문과 기존 야간 불빛도 사진의 표시 시간대에 맞춘다.

## 19. 지역

기존 firstSky/emerald/iron/frozen/aether/lostHeavens ID에 하늘·암석 팔레트를 대응한다. 캠페인에는 기존 챕터별 하늘 설정을 보존한다. 새로운 지역이나 지형 자원을 만들지 않았다.

## 20. 재난

기존 실제 비·안개·번개·운석·방어막·부하 표시를 보존한다. 입자 예산과 기존 섬광 감소·흔들림 설정을 존중한다. 사진의 맑은 조명 프리셋이 실제 재난을 중단하지 않는다. 재난 이펙트 전면 재제작은 하지 않았다.

## 21. 붕괴·손상·복구

실제 내구도가 낮은 시설에 금을 나타내는 표시를 추가했다. 내구도가 복구되면 사라진다. 기존 낙하·붕괴 원인·수리 효과·구조 이벤트를 유지하며 연출에서 새 손상을 계산하지 않는다.

## 22. 건설 연출

주요 건물의 미리보기를 실제 모델 실루엣으로 바꾸고 기존 유효성 색·점유 칸·경고를 유지한다. ghost 재질은 복제하므로 배치된 건물 재질을 오염시키지 않는다. 기존 배치 파동·완료 피드백을 유지한다. 장시간 자라나는 건설 애니메이션은 추가하지 않았다.

## 23. 로고·인물

직접 제작한 SVG 섬·도시·결정 마크와 기존 네 인물의 얼굴·복장·직업 장식을 추가했다. 시스템 글꼴을 사용하고 초상 접근성 이름은 선택 언어를 따른다. 새로운 인물이나 대사는 만들지 않았다.

## 24. 메뉴·HUD

브랜드 마크와 Phase 10 표기를 적용하고 그래픽·사진 설정을 한국어/영어로 제공한다. 기존 정보 구조·키보드 입력·모달·대비를 유지한다. 모든 HUD 아이콘을 새 아이콘 세트로 교체하지 않았다.

## 25. 세계·캠페인 지도

기존 발견 상태·항로·잠금·별·챕터 표시를 유지한다. 미발견 섬 정보를 드러내는 시각 장식이나 신규 지도 게임 규칙을 추가하지 않았다. 지도 전면 재디자인은 남은 범위이다.

## 26. 사진·시네마틱

일출·맑은 낮·저녁·밤·시네마틱·설계도와 구름 밀도, 1×/2× PNG, 선택 로고를 제공한다. 긴 변은 3840px로 제한하고 캡처 후 renderer 크기를 복원한다. 기존 실제 도시 오프닝·결말 투어와 건너뛰기는 유지한다. 사진 모드는 단독 시계를 멈추고 온라인 서버 시계는 계속 흐른다.

## 27. 외부 모델

glTF/GLB registry, 지연 로드, 경로별 캐시, 크기 검증과 절차형 fallback을 추가했다. 자체 제작 ballast.gltf 정상 로드와 요청 실패 복구를 실제 브라우저에서 확인한다. 모든 건물의 외부 에셋 완성이나 clip 자동 재생을 주장하지 않는다. ASSET_PIPELINE.md에 교체 규격과 13개 우선순위를 기록했다.

## 28. 화질

LOW/MEDIUM/HIGH/ULTRA가 DPR·그림자·구름·시민·차량·입자·섬 장식 예산에 연결된다. 기본 MEDIUM. 기존 접근성 선호는 보존한다. 화질·사진 설정으로 점유·판정·점수·공급·서버 시간을 변경하지 않는다.

## 29. 최적화

공유 상자 geometry와 제한된 팔레트 재질, 동일 재질 템플릿 병합, 건물·암석·구름·시민·차량 인스턴싱을 사용한다. 주요 건물은 LOW 또는 원거리에서 실루엣으로 단순화한다. 선택 상태에서는 상세 표현을 유지한다. 매 프레임 게임 store에 시각 상태를 쓰지 않는다. 병합 geometry는 정리 시 해제하며 고정 공유 리소스와 모델 캐시는 페이지 수명 동안 유지한다.

## 30. 저장 보호

도시 v5 및 기존 슬롯을 유지한다. graphicsVersion=1과 안전한 신규 기본값을 추가하고 알 수 없는 버전·품질·범위 밖 밀도를 거부한다. 이전 그림자·시민·모션 감소 선택을 임의로 덮어쓰지 않는다. 사진 상태는 저장·서버 프로토콜에 넣지 않는다.

## 31. 변경 파일

scene의 Environment/PrimaryFacilities/ArtPrimitives/FacilityDetails/TrafficGeometry/GhostFacility/PhotoCapture/assets/art, 기존 World/Buildings/BuildingField/LivingCity, visualStore, GraphicsSettings, Interface/CampaignUI/PlayTools, 설정 타입·기본값·저장 경계, 자체 SVG/glTF, graphics 단위 테스트·visual 브라우저 테스트·온라인 화질 검증, 아트·에셋·그래픽 문서가 주요 변경이다.

## 32. 개선 전후 이미지

변경 전 phase10-before.png와 phase9-photo.png를 보존했다. 변경 후 실제 브라우저·PNG 자료는 docs/images에 보관한다. 렌더링하지 않은 컨셉 이미지를 결과 화면으로 제시하지 않는다.

## 33. 실제 성능

변경 전 동일 대도시: 135건물·256플랫폼, 520 draw calls, 64,460 triangles, geometry 535, texture 2. Chrome SwiftShader 개발 빌드에서 평균 2.86FPS였다. 최종 86 draw calls, 81,852 triangles, geometry 71, texture 2였다. 평균 1.94FPS로 낮아져 FPS 개선은 주장하지 않는다. 기본 도시 자원은 geometry 102·texture 2로 복귀했다. VERIFICATION.md 및 원자료 JSON에 보존했다. 실제 GPU 60FPS 보장이 아니다.

## 34. 자동 테스트

이전 저장·신규 설정 경계·접근성 보존 테스트를 추가했다. 전체 255개 및 이후 추가한 경계 테스트를 포함한 4개가 통과했고, 현재 전체는 256개이다. 클라이언트·서버 빌드도 통과했다.

## 35. 브라우저 검증

사진 프리셋·도시 상태 불변·실제 PNG 크기·외부 모델 정상/실패를 검사한다. 기존 건축·도시·다층·재난·세계·실제 온라인 전체 흐름을 재검증하며 온라인 두 클라이언트의 화질을 다르게 설정한다. Chrome 전체 28개, 최종 시각·성능 5개, 최종 Edge 6개가 통과했다. 일반 실행에서 수동 성능 시나리오는 제외한다. VERIFICATION.md에 범위를 기록했다.

## 36. 발견한 문제·제약

초기 신규 테스트가 도시 실험실 버튼의 보조 영문 이름을 누락해 실패했다. 실제 접근성 이름에 맞춰 수정했다. 손상 코어·정지 발전기·점유되지 않은 야간 주택·삭제된 플랫폼의 나무 표현도 점검해 보완했다. 기존 의존성 audit 항목, SQLite 실험 경고와 Three 청크 크기 권고는 남아 있다.

## 37. 미구현·미검증

프롬프트의 우선 구현 허용 지침에 따라 핵심 섬·건물·코어·미리보기·조명에 집중했다. 전체 시설·선박·다리의 고유 고급 에셋, 지도 전면 개편, 새 시네마틱, 블룸/AO/DOF, 볼륨 구름, 애니메이션 clip 파이프라인은 남아 있다. 모든 시설 조합의 시각적 아름다움, 실제 GPU·저사양 실기기 성능, 장시간 WAN 온라인은 검증하지 않았다.

## 38. 다음 단계 준비

게임 규칙과 시각 정의, 저장과 임시 사진 상태를 분리했다. 에셋 교체·화질·검증 기준이 마련되어 다음 단계에서도 실제 게임 상태를 기준으로 확장할 수 있다. Phase 11–13 기능, 공개 배포, 병합, DNS 변경은 하지 않았다.
