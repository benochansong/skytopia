## 1. 프로젝트 개요

기존 SKYTOPIA: AETHER RISING 프로젝트를 기반으로 Phase 9 개발을 진행한다.

- 게임명: SKYTOPIA: AETHER RISING

- 플랫폼: PC 웹 브라우저
- 기본 언어: 한국어
- 추가 지원 언어: 영어

기존 Phase 1~8에서는 다음 게임 시스템의 구현을 목표로 개발하였다.

- 도시 운영
- 전력과 식량
- 산업과 경제
- 스토리 캠페인
- 다층 도시
- 수직 하중
- 교량 및 승강기
- 자연재해
- 재난 대응
- 생존 모드

## 2. 이번 단계의 핵심 목표

**기능이 많은 게임에서 실제로 재미있는 게임으로 발전시킨다.**

플레이어가 다음 감정을 느낄 수 있도록 한다.

- 블록을 배치하는 순간의 만족감
- 복잡한 공간을 효율적으로 사용하는 재미
- 새로운 건축 블록에 대한 기대감
- 도시가 점점 성장하는 성취감
- 구조적 위험을 해결하는 긴장감
- 자신만의 아름다운 도시를 완성하는 즐거움
- 실패한 도시를 다시 설계하고 싶은 도전 의식
- 한 판을 마친 후 다시 플레이하고 싶은 동기

게임의 재미를 해치는 불필요한 복잡성과 반복 작업을 줄인다.

다만 SKYTOPIA의 핵심 정체성인 무작위 블록 건축과 구조 안정성은 반드시 유지한다.

## 4. 전체 게임 플레이 진단

새로운 기능을 추가하기 전에 실제 게임을 실행하여 플레이 경험을 분석한다.

### 진단 항목

1. 게임 시작 후 첫 건축까지 걸리는 시간
2. 첫 번째 건축 블록 배치의 이해도
3. 마우스 및 키보드 조작의 편의성
4. 카메라 조작의 불편함
5. 블록 이동과 회전의 정확성
6. 건축 가능 위치의 이해도
7. 블록 공급으로 인한 대기시간
8. 도시 성장 속도
9. 구조 위험의 이해도
10. 자원 부족 원인의 이해도
11. 미션 진행의 반복성
12. 게임 화면의 복잡성
13. 불필요한 클릭 횟수
14. 게임 실패 원인의 명확성
15. 다시 플레이하고 싶은 동기
16. 프레임 저하 및 입력 지연

가능한 경우 실제 브라우저에서 다음 구간을 플레이한다.

- 게임 시작 후 최초 5분
- 최초 15분
- 첫 번째 캠페인 미션
- 구조 공학 미션
- 다층 건축 미션
- 재난 생존 미션
- 자유 건설
- 다중 도시 운영
- 온라인 대전

발견한 문제를 다음 등급으로 분류한다.

- Critical: 게임 진행 불가능
- High: 핵심 게임 플레이를 심각하게 방해
- Medium: 불편하거나 반복적인 문제
- Low: 작은 시각적 및 편의성 문제

실제로 발견된 문제를 우선 수정한다.

## 5. SKYTOPIA의 핵심 정체성 재확립

SKYTOPIA는 일반적인 도시 건설 게임이 아니다.

다음 네 가지 요소가 게임의 중심에 있어야 한다.

### A. FALLING BLOCKS

무작위로 공급되는 다양한 건축 블록을 활용하여 도시를 건설한다.

### B. SPATIAL STRATEGY

제한된 3차원 공간에서 건축물의 형태와 위치를 고려한다.

### C. STRUCTURAL ENGINEERING

모든 건축물이 실제 질량을 가지며 도시의 구조와 균형에 영향을 준다.

### D. CIVILIZATION GROWTH

플레이어의 건축 선택이 인구, 경제, 산업 및 문명 발전으로 이어진다.

기존 기능이 이러한 정체성을 약화시키고 있다면 개선한다.

모든 시설을 자유롭게 선택하여 건설하는 일반 도시 건설 게임으로 변질시키지 않는다.

반대로 무작위 블록 때문에 도시 운영이 불가능해지는 불합리한 상황도 방지한다.

## 6. 핵심 게임 플레이 순환 개선

다음 순환이 끊김 없이 자연스럽게 이어지도록 한다.

새로운 블록 등장
→ 다음 블록 확인
→ 배치 위치 고민
→ 블록 이동 및 회전
→ 예상 결과 확인
→ 건축물 배치
→ 도시의 변화 확인
→ 보상 및 새로운 문제 발생
→ 다음 건축 블록 등장

플레이어가 건축물 하나를 배치할 때마다 의미 있는 변화가 발생해야 한다.

예시:

- 새로운 주택 건설 후 주민 증가
- 발전소 건설 후 정전 구역 정상화
- 농장 건설 후 식량 부족 해결
- 새로운 플랫폼 건설 후 도시 확장
- 교량 건설 후 분리된 도시 구역 연결
- 부양장치 건설 후 도시의 기울기 감소
- 기둥 보강 후 구조 위험 감소
- 공원 건설 후 주민 행복도 상승

수치 변화뿐 아니라 3D 화면에서도 이러한 결과를 명확하게 표현한다.

## 7. 건축 조작감 개선

건축 블록의 이동과 회전이 정확하고 부드럽게 작동하도록 한다.

### 이동 시스템

- 키보드 입력에 즉각 반응
- 불필요한 입력 지연 제거
- 일정한 격자 단위 이동
- 키를 누르고 있을 때 연속 이동
- 초기 반복 입력 지연 설정
- 이동 속도 조절

### 회전 시스템

- Q / E를 이용한 정확한 90도 회전
- 부드러운 회전 애니메이션
- 회전 후 격자 위치 유지
- 입체 구조 블록의 허용 축 회전
- 잘못된 회전 방지

회전 애니메이션과 실제 격자 판정이 불일치하지 않도록 한다.

### 회전 보정

블록이 기존 건축물이나 경계에 인접하여 회전하기 어려운 경우 작은 범위의 위치 보정을 적용할 수 있다.

보정 범위는 최대 1~2칸 정도로 제한한다.

플레이어가 의도하지 않은 먼 위치로 블록이 순간 이동하지 않도록 한다.

온라인 경기에서도 동일한 회전 보정 규칙을 적용한다.

## 8. 마우스 건축 시스템 개선

마우스 중심의 직관적인 건축 조작을 제공한다.

### 기본 동작

- 마우스 이동: 배치 대상 격자 선택
- 왼쪽 클릭: 건축물 배치
- 오른쪽 드래그: 카메라 회전
- 가운데 버튼 드래그: 화면 이동
- 마우스 휠: 확대 및 축소

블록이 마우스 위치에 자연스럽게 대응하도록 한다.

다층 도시에서 마우스가 가리키는 층과 실제 건축 층이 일치해야 한다.

UI 버튼을 클릭할 때 뒤쪽 게임 화면에 건축물이 잘못 배치되는 문제를 방지한다.

카메라 회전이 끝난 직후 불필요한 건축 명령이 발생하지 않도록 한다.

마우스와 키보드 입력을 혼합하여 사용해도 조작 상태가 충돌하지 않아야 한다.

## 9. 건축 블록 배치 미리보기

기존 Ghost Block 시스템을 개선한다.

### 배치 상태

- 초록색: 안전하게 건축 가능
- 노란색: 건축 가능하지만 일부 문제 존재
- 주황색: 구조 또는 운영 위험
- 빨간색: 건축 불가능

색상과 함께 아이콘 및 짧은 메시지를 제공한다.

### 배치 불가능 원인

- 플랫폼이 없습니다.
- 기존 건축물과 겹칩니다.
- 지지 기둥이 부족합니다.
- 허용된 건축 범위를 벗어났습니다.
- 현재 층에서 설치할 수 없습니다.
- 필요한 기술이 해금되지 않았습니다.
- 건축 자원이 부족합니다.

플레이어가 건축할 수 없는 이유를 직접 추측하게 하지 않는다.

### 예상 결과

필요한 경우 배치 전 다음 정보를 보여준다.

- 예상 인구 증가
- 예상 전력 수요
- 추가 질량
- 예상 안정도 변화
- 도로 및 전력 연결 여부
- 위험해지는 구조물

기본 화면에는 가장 중요한 정보만 표시한다.

상세 분석은 선택적으로 확인할 수 있도록 한다.

## 10. 스마트 스냅 기능

건축 블록의 배치 위치를 쉽게 맞출 수 있도록 스마트 스냅 기능을 추가하거나 개선한다.

### 스냅 대상

- 기존 플랫폼 가장자리
- 도로 연결부
- 전력 연결부
- 구조 기둥
- 교량 연결점
- 계단과 승강기
- 상층 플랫폼
- 하부 현수 구조

스냅 기능은 플레이어의 의도와 가까운 위치에서만 작동한다.

원하지 않는 위치로 강제로 이동시키지 않는다.

여러 스냅 위치가 존재하면 현재 마우스 또는 키보드 이동 방향을 우선한다.

스마트 스냅 기능을 설정에서 비활성화할 수 있도록 한다.

전문가 플레이어는 보조 기능 없이 직접 배치할 수 있어야 한다.

## 11. 카메라 조작 개선

기존 3D 카메라 시스템의 불편함을 개선한다.

### 요구사항

- 부드러운 360도 회전
- 일정한 확대 및 축소 속도
- 선택한 층에 자연스럽게 집중
- 카메라 이동 감도 조절
- 도시 중심으로 빠르게 복귀
- 건축물에 가려진 공간 확인
- 하부 산업시설 확인
- 위험 구조물에 빠르게 이동
- 카메라 충돌 최소화

### 새로운 편의 기능

선택한 건축물에 카메라 집중.

최근 건설한 구역으로 이동.

현재 미션의 주요 목표 구역 강조.

위험 경고를 클릭하면 해당 구조물로 이동.

자동 카메라 이동이 플레이어의 조작을 방해하지 않도록 한다.

카메라 이동 중 새로운 입력이 발생하면 사용자의 조작을 우선한다.

## 12. 건축 블록 낙하 속도 개선

블록 낙하 방식은 SKYTOPIA의 핵심 재미다.

기존 제한시간이 지나치게 짧거나 길지 않은지 실제 플레이를 통해 검토한다.

### 초기 조정 가안

| 난이도 | 블록 배치 시간 |
|---|---:|
| 스토리 | 30초 |
| 일반 | 20초 |
| 전문가 | 12초 |
| 제한 블록 경쟁 | 경기 규칙에 따라 설정 |
| 자유 건설 | 시간제한 선택 가능 |

시간 제한을 모든 게임 모드에 동일하게 적용하지 않는다.

### 소프트 드롭

플레이어가 원하는 경우 블록의 하강 속도를 높일 수 있도록 한다.

### 하드 드롭

Space 키 또는 배치 버튼을 사용하면 유효한 위치에 즉시 배치한다.

### 시간 종료 처리

시간이 종료되었을 때 현재 위치가 유효하면 자동 배치할 수 있다.

유효하지 않은 위치에서는 기존 재활용 또는 안전한 실패 처리 규칙을 사용한다.

시간제한 때문에 의도하지 않은 치명적 구조 붕괴가 반복되는 상황을 방지한다.

## 13. 블록 공급 대기시간 제거

플레이어가 현재 블록을 빠르게 배치했음에도 다음 블록이 등장할 때까지 오래 기다려야 하는 문제가 있는지 확인한다.

건축 완료 직후 다음 블록을 자연스럽게 공급한다.

### 초기 목표

- 건축 완료 시 즉각적인 시각적 피드백
- 약 0.2~0.5초의 짧은 전환
- 다음 블록 공급
- 즉시 새로운 건축 조작 가능

위 수치는 실제 조작감을 기준으로 조정한다.

건축 애니메이션이 종료될 때까지 모든 입력을 잠그지 않는다.

빠르게 플레이하는 사용자와 신중하게 설계하는 사용자 모두 자신의 속도로 건축할 수 있도록 한다.

## 14. 블록 공급 다양성 개선

기존 무작위 공급 시스템을 분석한다.

특정 건축물이 지나치게 자주 등장하거나 필수 건축물이 지나치게 오랫동안 등장하지 않는 문제가 있는지 확인한다.

### 개선 방향

- Bag Randomizer 유지 또는 개선
- 시드 기반 난수 유지
- 시설별 최소 공급 보장
- 지나친 동일 시설 연속 등장 제한
- 도시 발전 단계에 따른 공급 변화
- 필요 시설의 제한적인 공급 확률 보정

예시:

주거시설이 연속으로 등장하지만 발전소와 도로가 전혀 공급되지 않아 인구를 늘릴 수 없는 상황을 완화한다.

다만 플레이어가 원하는 시설이 항상 즉시 등장하게 해서는 안 된다.

무작위성과 전략적 대응 능력의 균형을 유지한다.

랭크 경쟁에서는 모든 플레이어에게 동일한 공급 순서를 유지한다.

싱글 플레이의 적응형 공급 정책을 온라인 경쟁에 무조건 적용하지 않는다.

## 18. 건축 콤보 시스템

건축의 연속성과 성취감을 강화하기 위한 가벼운 콤보 시스템을 추가한다.

새로운 복잡한 경제 시스템으로 발전시키지 않는다.

### 콤보 발생 예시

- 주거시설과 도로를 연속으로 연결
- 발전소와 전력 수요 시설을 연결
- 농장과 저장시설 연결
- 플랫폼과 지지 기둥을 연속으로 설치
- 교량을 이용하여 분리 구역 연결
- 위험한 구역의 구조 보강 완료

### 콤보 명칭

- PERFECT CONNECTION
- POWER ONLINE
- BALANCED BUILD
- STRUCTURAL MASTER
- CITY GROWTH
- SKY EXPANSION

콤보는 실제로 의미 있는 건축 성과를 기반으로 발생한다.

아무 의미 없이 빠르게 블록을 배치하는 행동에만 높은 보상을 제공하지 않는다.

콤보 보상은 우선 점수와 시각적 성취감을 중심으로 제공한다.

자원 보상을 추가할 경우 경제 밸런스를 무너뜨리지 않도록 제한한다.

온라인 경기에서는 검증된 공통 콤보 규칙만 사용한다.

## 19. 건축 시너지 시스템 개선

서로 관련된 건축물이 적절하게 배치되었을 때 작은 운영상의 이점을 제공한다.

### 예시 A — 주거 구역

주거시설과 공원, 의료시설이 연결되어 있으면 생활환경이 개선된다.

### 예시 B — 산업 구역

공장과 창고, 물류시설이 연결되어 있으면 생산 및 운송 효율이 향상된다.

### 예시 C — 농업 구역

농장과 식량 저장시설이 연결되어 있으면 식량 공급 효율이 향상된다.

### 예시 D — 에너지 구역

발전시설과 에너지 저장시설, 전력 중계기가 연결되어 있으면 비상 대응 능력이 개선된다.

### 예시 E — 구조 구역

복수의 유효한 지지 경로가 존재하면 구조적 회복력이 향상된다.

기존 도시 운영 및 전문화 시스템의 기능과 중복되는 보너스를 무분별하게 추가하지 않는다.

건축물의 실제 연결 상태와 가동 여부를 반영한다.

보너스는 상한을 설정하여 무한 중첩을 방지한다.

## 20. 도시 성장의 시각적 성취감

플레이어가 도시의 발전을 수치가 아니라 화면에서 체감할 수 있도록 개선한다.

### 성장 표현

- 주민 수가 증가하면 도시 활동 증가
- 주거시설의 창문 조명 증가
- 산업시설 정상 가동
- 물류 차량 활동
- 공원 및 광장의 주민 활동
- 발전소 에너지 효과
- 공중항구의 비행선 활동
- 도시 등급에 따른 시각적 변화

### 성장 이정표

- 최초 주거시설 완성
- 인구 25명
- 인구 50명
- 인구 100명
- 최초 상층 도시
- 최초 공중 교량
- 최초 재난 극복
- 최초 교역로 완성
- 새로운 도시 개척

중요한 성장 목표를 달성하면 짧은 축하 효과와 알림을 제공한다.

모든 작은 성과마다 화면을 강제로 멈추지 않는다.

## 21. 건축 완료 애니메이션 개선

건축물 배치가 시각적으로 만족스럽게 느껴지도록 한다.

### 기본 효과

- 블록의 부드러운 하강
- 격자 위치에 정확한 결합
- 짧은 충격 및 결합 효과
- 작은 에테르 입자
- 건축물 점등
- 건축 완료 사운드

### 구조시설

기둥과 보강재가 실제 구조에 결합하는 느낌을 표현한다.

### 발전시설

건축 완료 후 에테르 코어가 활성화되는 효과를 표현한다.

### 도로

현재 단계에서는 기존 모델을 활용한 게임 플레이 피드백 개선에 집중한다.

## 22. 구조 안정성의 직관성 개선

구조 공학 시스템을 처음 접하는 플레이어도 쉽게 이해할 수 있도록 한다.

다음 세 가지 핵심 질문에 즉시 답할 수 있어야 한다.

1. 현재 도시가 안전한가?
2. 어느 구역이 위험한가?
3. 위험을 어떻게 해결할 수 있는가?

### 기본 안정성 표시

- 안전
- 주의
- 위험
- 붕괴 임박

종합 안정도를 표시하되 부양력 부족, 무게중심 불균형 및 구조 과부하를 구분한다.

### 경고 예시

나쁜 예:

"구조 오류 17 발생."

좋은 예:

"동쪽 플랫폼의 연결부가 무거운 공장을 지탱하기 어렵습니다."

### 해결 방법

- 추가 기둥 설치
- 구조 연결부 보강
- 무거운 건축물 이동 또는 철거
- 부양장치 설치
- 대체 지지 경로 확보

실제 게임 상태를 기반으로 정확한 원인과 해결 방법을 안내한다.

## 23. 구조 위험의 시각적 표현 개선

위험 상태를 HUD 숫자만으로 표현하지 않는다.

다음 요소를 활용한다.

- 도시의 기울기
- 위험한 연결부의 강조
- 구조물의 미세한 흔들림
- 플랫폼의 균열
- 부양장치 출력 변화
- 구조 하중 방향
- 붕괴 임박 경고

위험이 발생하면 해당 구역을 쉽게 찾을 수 있어야 한다.

모든 건축물이 동시에 빨간색으로 표시되어 정확한 위험 원인을 구분하기 어려운 상황을 피한다.

가장 위험한 구조물부터 우선적으로 강조한다.

위험이 해결되면 도시가 안정적인 상태로 돌아오는 만족스러운 시각 효과를 제공한다.

경쟁 모드에서는 모든 참가자에게 동일한 보조 기능 규칙을 적용한다.

보조 기능을 줄인다고 건축물의 실제 충돌 판정이나 서버 검증을 비활성화하지 않는다.

## 25. 도시 운영의 불필요한 복잡성 감소

기존 도시 경제와 자원 관리 시스템을 분석한다.

다음 문제를 개선한다.

- 중복되는 생산시설
- 너무 잦은 자원 부족 경고
- 비효율적인 시설 관리
- 노동력 배분의 과도한 수동 조작
- 전력망 연결의 반복 작업
- 여러 도시를 관리하는 부담

### 기본 운영 화면

관련 문제가 발생하면 해당 자원의 상세 정보를 자동으로 쉽게 확인할 수 있도록 한다.

## 26. CITY ADVISOR 개선

기존 도시 조언 시스템을 실제 플레이에 더욱 유용하도록 개선한다.

### 우선순위

1. 즉시 대응해야 하는 치명적 구조 위험
2. 부양력과 필수 전력 부족
3. 식량 고갈 위험
4. 주요 교통망 단절
5. 경제적 문제
6. 도시 발전 기회

한 번에 가장 중요한 문제를 최대 3개 정도 표시한다.

### 조언 구성

현재 문제:

"식량 생산량이 부족합니다."

원인:

"현재 주민 80명의 식량 소비량이 농장 생산량을 초과합니다."

해결 방법:

"농장을 추가하거나 산업시설이 사용하는 노동력을 농업시설에 우선 배분하십시오."

관련 시설 또는 분석 화면으로 이동할 수 있는 버튼을 제공한다.

실제로 존재하지 않는 건축물이나 사용할 수 없는 기술을 해결책으로 제시하지 않는다.

## 27. 위험 및 경고 피로도 감소

모든 작은 문제가 지속적으로 경고음을 발생시키지 않도록 한다.

경고를 다음 등급으로 구분한다.

### 정보

도시 운영에 참고할 수 있는 일반적인 정보.

### 주의

나중에 대응해야 하는 문제.

### 위험

빠른 대응이 필요한 문제.

### 긴급

도시 붕괴 또는 핵심 시설 정지 위험.

동일한 경고의 반복 횟수를 제한한다.

이미 확인한 경고는 상태가 악화되거나 새로운 문제가 발생할 때 다시 표시할 수 있다.

위험이 해결되면 관련 경고를 즉시 제거한다.

경고가 화면에 계속 쌓여 건축 조작을 방해하지 않도록 한다.

## 28. 실수 방지 및 제한적 실행 취소

건축 과정에서 발생하는 단순 조작 실수를 줄인다.

### 실행 취소 가능 대상

- 최근 건축물 배치
- 일부 플랫폼 설치
- 일부 구조 보강
- 잘못된 회전으로 인한 배치

실행 취소는 해당 행동 이후 발생한 게임 상태 변화와 연결 관계를 검증한다.

이미 주민이 정착하거나 자원이 생산되거나 구조 피해가 발생한 이후에는 단순 실행 취소를 제한한다.

실행 취소를 통해 자원을 복제하거나 붕괴를 악용하여 되돌리는 문제가 발생하지 않도록 한다.

### 모드별 정책

- 자유 건설: 넉넉한 실행 취소
- 스토리 난이도: 제한적인 실행 취소
- 일반 난이도: 제한 횟수 적용
- 전문가 난이도: 선택적으로 비활성화
- 온라인 경쟁: 기본적으로 비활성화

온라인 협동에서는 서버 검증과 다른 플레이어의 상태를 고려한다.

## 29. 지루한 대기시간 개선

플레이어가 특별한 행동 없이 오랫동안 기다려야 하는 구간을 찾아 개선한다.

### 검토 대상

- 인구 성장 대기
- 전력망 정상화 대기
- 자원 생산 대기
- 기술 연구 대기
- 비행선 이동 대기
- 구조 수리 대기
- 미션 완료 조건 유지시간
- 재난 접근 대기

대기시간 자체가 의미 있는 전략 요소라면 유지한다.

대기 중 다른 건축 및 운영 행동을 수행할 수 있도록 한다.

필요한 경우 기존 배속 시스템을 활용한다.

모든 시설 생산량을 무조건 증가시키거나 시간을 대폭 단축하여 게임의 전략적 의미를 제거하지 않는다.

온라인 경기에서는 서버 기준 시간을 유지한다.

## 30. 미션 진행 속도 개선

기존 캠페인 Stage 01~30의 실제 구현 상태를 확인한다.

각 미션이 지나치게 느리거나 반복적으로 진행되는지 검토한다.

### 초반 미션

- 빠른 첫 건축
- 짧은 설명
- 즉각적인 목표 달성 경험
- 기본 조작 학습
- 과도한 도시 운영 요구 금지

### 중반 미션

- 새로운 구조 문제
- 도시 운영과 건축의 균형
- 기존 시스템의 새로운 조합

### 후반 미션

- 종합적인 설계 능력

기존 스테이지의 이름, 세계관, 주요 스토리는 가능한 한 유지한다.

### 구조 공학 미션

### 경제 미션

미션별로 하나 이상의 고유한 전략적 특징을 제공한다.

- 최종 도시 완성

최종 승리 조건은 항상 확인할 수 있어야 한다.

중간 목표를 반드시 정해진 순서로만 완료해야 하는 방식은 학습용 미션에 한정한다.

일반 미션에서는 플레이어가 자신만의 전략을 선택할 수 있도록 한다.

## 33. 전략적 선택의 다양성

여러 건축 전략이 실제로 유효하도록 기존 시스템을 조정한다.

### 넓고 낮은 도시

- 낮은 수직 구조 위험
- 넓은 부유 플랫폼 필요
- 외곽 연결부 부담 증가

### 높고 밀집된 도시

- 높은 공간 효율
- 높은 인구 밀도
- 기둥 및 수직 하중 부담 증가

### 산업 중심 도시

- 높은 건축 자원 생산
- 높은 전력과 노동력 수요
- 구조적 질량 증가

### 주거 중심 도시

- 높은 인구와 생활환경
- 식량 및 전력 소비 증가
- 산업 생산의 상대적 부족

### 재난 대응 중심 도시

- 높은 회복력
- 안정적인 구조
- 방어시설의 건축 비용과 질량 부담

### 교역 중심 도시

- 전문화된 자원 생산
- 효율적인 도시 간 연결
- 교역로 단절 위험

특정 전략만 모든 상황에서 최적이 되는 문제를 찾고 개선한다.

새로운 대규모 콘텐츠를 추가하기보다 기존 시스템의 활용 가치를 높인다.

## 34. 건축 퍼즐의 재미 강화

SKYTOPIA의 초기 아이디어였던 테트리스형 공간 퍼즐 요소를 강화한다.

### 개선 대상

- 다양한 블록 형태의 실제 활용
- 남은 빈 공간을 효율적으로 채우는 전략
- L형 플랫폼 활용
- T형 도로 활용
- 좁은 구역의 건축
- 여러 층의 연결
- 상층 및 하부 공간 활용
- 적절한 블록 보관

모든 건축물이 사실상 1×1 사각형처럼 느껴지는 문제가 있다면 개선한다.

각 블록의 형태가 실제 점유 및 연결 전략에 의미를 가져야 한다.

단순히 크기가 큰 건축물이 항상 좋은 선택이 되지 않도록 한다.

작고 가벼운 블록이 좁은 공간이나 구조적으로 취약한 위치에서 유용하도록 한다.

## 35. 공간 효율 평가

기존 도시 점수와 건축 평가에 공간 활용의 의미를 강화한다.

### 평가 요소

- 실제 사용 가능한 플랫폼 공간
- 건축물 점유 비율
- 연결되지 않은 고립 공간
- 접근 가능한 건축 구역
- 구조적 여유
- 공원과 생활 공간
- 향후 확장 가능성

모든 빈 공간을 건축물로 채우는 것이 높은 점수를 받도록 하지 않는다.

필요한 도로, 공원, 안전시설 및 향후 확장 공간도 긍정적으로 평가한다.

도시의 효율성을 단순한 건축물 개수만으로 평가하지 않는다.

## 36. 자유 건설 모드 개선

자유 건설을 원하는 플레이어에게 편안한 건축 경험을 제공한다.

### RELAXED BUILDING

- 선택적 시간제한
- 풍부한 자원
- 자연재해 비활성화 가능
- 건축 중심 경험
- 아름다운 도시 감상

### CLASSIC SKYTOPIA

- 무작위 건축 블록
- 일반적인 도시 운영
- 구조적 위험
- 기본 성장 목표

### ENGINEERING CHALLENGE

- 제한적인 부양력
- 정교한 구조 설계
- 높은 하중 관리 중요도

### SURVIVAL BUILDING

- 자연재해 활성화
- 자원 제한
- 도시 회복력 중심

기존 자유 건설 설정을 활용하여 구현한다.

새로운 게임 모드마다 완전히 별개의 게임 시스템을 중복 생성하지 않는다.

## 37. 생존 모드 재미 개선

기존 생존 모드를 분석한다.

재난이 반복적으로 발생하고 플레이어가 계속 수리만 해야 하는 구조가 되지 않도록 한다.

### 개선 방향

- 재난별 다른 대응 전략
- 웨이브 사이의 의미 있는 건축 시간
- 새로운 도시 발전 목표
- 제한적인 보상 선택
- 재난 대응 후 성장 기회
- 도시 회복력 향상
- 다음 재난 정보 제공

### 웨이브 보상 개선

플레이어에게 다음과 같은 선택지를 제공할 수 있다.

- 도시 성장 지원
- 구조 안정성 지원
- 경제 회복 지원
- 재난 방어 지원

재난을 극복할 때마다 도시가 발전할 수 있어야 한다.

피해 복구만 반복하다가 결국 패배하는 단조로운 구조를 피한다.

## 38. 다중 도시 운영 부담 감소

Phase 7의 다중 도시 기능이 구현되어 있다면 관리 편의성을 개선한다.

### 핵심 개선

- 모든 도시의 상태를 한눈에 확인
- 위험 도시 우선 표시
- 자원 부족 도시 강조
- 교역 가능한 공급 도시 추천
- 자동 교역 설정 간소화
- 비행선 운항 상태 표시
- 도시 전환 속도 개선

현재 화면에 표시되지 않는 도시가 지나치게 많은 수동 관리를 요구하지 않도록 한다.

비활성 도시의 건축 블록 낙하 시간은 기존 정지 정책을 유지한다.

도시 경제 및 재난은 기존 세계 시뮬레이션 규칙을 따른다.

자동화 기능을 활용하여 건축의 재미보다 관리 작업이 더 많아지는 문제를 줄인다.

## 39. 온라인 경쟁 플레이 개선

Phase 8의 실제 구현된 온라인 기능을 대상으로 개선 작업을 진행한다.

### SKY DUEL

- 빠르고 명확한 경기 시작
- 동일한 블록 공급
- 직관적인 점수 비교
- 정확한 건축 판정
- 경기 종료의 명확성
- 결과 화면 개선

### 제한 블록 퍼즐

- 짧은 경기 시간
- 이해하기 쉬운 목표
- 실질적인 공간 전략
- 빠른 재경기

### 구조 공학 경쟁

- 명확한 하중 시험
- 구조 효율 비교
- 결과 차이에 대한 설명

### 재난 경쟁

- 동일 재난 일정
- 준비 시간 확보
- 설계에 따른 결과 차이
- 역전 가능성

온라인 경기의 서버 권위와 부정행위 검증을 유지한다.

조작감을 개선하기 위해 클라이언트가 임의로 게임 결과를 확정하도록 변경하지 않는다.

온라인 기능이 미완성이라면 가짜 상대방이나 가짜 랭킹을 만들어 대체하지 않는다.

## 40. 협동 플레이 개선

기존 협동 도시 건설 기능이 실제로 구현되어 있다면 두 플레이어의 협력 경험을 개선한다.

### 개선 항목

- 다른 플레이어의 건축 예정 위치
- 위치 핑
- 구조 위험 공유
- 자원 부족 공유
- 역할 분담 안내
- 공동 목표 진행률
- 공유 자원 사용 기록

한 플레이어가 건축하는 동안 다른 플레이어가 할 일이 없어지는 상황을 방지한다.

양쪽 플레이어의 활동이 공동 도시의 발전에 의미 있게 기여해야 한다.

동시 건축 시 발생하는 격자 충돌과 자원 중복 소비를 다시 검증한다.

## 41. 승리 화면 개선

미션 완료와 경기 승리가 만족스럽게 느껴지도록 한다.

### 표시 요소

- 완성된 도시
- 최종 점수
- 도시 인구
- 도시 안정도
- 주요 건축 성과
- 해결한 구조 위험
- 주민 행복도
- 경제 성과
- 선택 목표
- 새로운 기록
- 획득한 보상

실제로 건설한 도시를 카메라가 부드럽게 보여준다.

미션에서 사용하지 않은 시스템은 결과 평가에서 제외한다.

과도하게 긴 승리 연출을 강요하지 않는다.

다음 미션과 다시 플레이 버튼을 쉽게 사용할 수 있도록 한다.

## 42. 실패 화면 개선

실패 결과가 좌절감만 주는 것이 아니라 새로운 도전의 동기가 되도록 한다.

### 실패 원인 표시

- 최초 구조 실패 지점
- 부양력 부족
- 전력망 단절
- 식량 부족
- 핵심 시설 파손
- 미션 제한시간 초과
- 제한 블록 소진

실제 발생한 주요 이벤트를 바탕으로 실패 원인을 분석한다.

### 개선 조언 예시

"도시의 총부양력은 충분했지만 동쪽 외곽 연결부에 하중이 집중되었습니다."

"다음 플레이에서는 공장을 중심부에 배치하거나 외곽 플랫폼에 추가 지지 구조를 설치해보십시오."

다음 기능을 제공한다.

- 빠른 다시 시작
- 체크포인트 복원
- 난이도 변경
- 관련 훈련 선택
- 실패한 도시의 마지막 상태 확인

빠른 다시 시작 시 불필요하게 긴 로딩과 반복 스토리 연출을 최소화한다.

## 43. 도시 감상 모드

플레이어가 자신이 건설한 도시를 아름답게 감상할 수 있도록 기존 카메라 기능을 확장한다.

### PHOTO MODE

- HUD 숨기기
- 자유 카메라
- 도시 전체 보기
- 시간대 선택
- 구름 및 환경 효과 설정
- 구조 분석 오버레이 숨기기
- 기본 화면 복귀

가능하다면 Canvas 기반 스크린샷 저장 기능을 구현한다.

싱글 플레이에서 사진 모드 사용 시 게임 시간을 정지할 수 있도록 한다.

온라인 경쟁에서는 사진 모드가 경기 시간이나 상태를 임의로 변경하지 않도록 한다.

사진 모드는 새로운 게임 규칙이 아니라 기존 건설 성과를 감상하는 편의 기능으로 구현한다.

## 45. 사용자 인터페이스 정리

### 기본 화면 원칙

3D 도시가 화면의 중심이어야 한다.

플레이어는 현재 상황을 빠르게 이해할 수 있어야 한다.

다음 정보의 우선순위를 높인다.

1. 현재 건축 블록
2. 건축 가능 여부
3. 현재 미션 목표
4. 도시의 안정성
5. 주요 자원 부족
6. 다음 건축 블록

상세 경제, 기술 연구, 구조 분석, 교역 정보는 별도의 확장 패널로 관리한다.

불필요하게 많은 패널을 동시에 열지 않는다.

한국어와 영어 UI 모두 화면에서 잘리지 않도록 한다.

현재 단계에서는 전체 디자인 시스템을 변경하기보다 기능적 가독성을 개선한다.

## 52. 필수 플레이 테스트

### 테스트 A — 첫 번째 건축

새로운 게임에서 첫 번째 블록을 배치한다.

검증:

- 조작 방법 이해
- 마우스 선택
- 회전
- 정확한 배치
- 건축 완료 피드백
- 다음 블록 공급

### 테스트 B — 빠른 연속 건축

블록을 연속으로 빠르게 배치한다.

검증:

- 입력 지연
- 다음 블록 공급
- 중복 배치
- 애니메이션 충돌
- 자원 차감
- 시각적 피드백

### 테스트 C — 어려운 공간 배치

좁은 공간과 외곽 지역에 여러 형태의 블록을 배치한다.

검증:

- 회전 보정
- 스마트 스냅
- 정확한 점유 판정
- 잘못된 배치 안내

### 테스트 D — 다층 건축

상층 및 하부 플랫폼에 건축물을 배치한다.

검증:

- 층 선택
- 카메라 이동
- 가시성
- 마우스 Raycasting
- 지지 구조 판정

### 테스트 E — 구조 위험

의도적으로 무게중심과 하중 문제를 발생시킨다.

검증:

- 위험 위치 표시
- 정확한 원인
- 적절한 해결 조언
- 구조 보강
- 안정성 회복

### 테스트 F — 도시 운영

전력과 식량 부족을 발생시키고 해결한다.

검증:

- 자원 경고
- 문제 원인
- 추천 행동
- 정상화
- 시각적 변화

### 테스트 G — 캠페인

초반, 중반, 후반의 대표적인 미션을 플레이한다.

검증:

- 목표 명확성
- 진행 속도
- 반복감
- 미션 완료 가능성
- 결과 화면
- 다시 시작

### 테스트 H — 생존 모드

여러 재난 웨이브를 진행한다.

검증:

- 재난 대비 시간
- 위험 안내
- 복구 가능성
- 웨이브 보상
- 도시 성장
- 반복 플레이 가치

### 테스트 I — 다중 도시

여러 공중 도시를 전환하고 교역을 관리한다.

검증:

- 도시 전환 속도
- 자원 정보 가독성
- 교역 상태
- 위험 도시 안내
- 비활성 도시 상태 유지

### 테스트 J — 온라인 경기

실제 구현된 온라인 경쟁 모드를 테스트한다.

검증:

- 방 생성 및 참가
- 입력 반응성
- 서버 건축 검증
- 상태 동기화
- 경기 결과
- 재접속
- 기존 싱글 플레이 보호

### 테스트 K — 저장 및 불러오기

기존 도시와 새로운 설정을 저장하고 복원한다.

검증:

- 기존 데이터 유지
- 새로운 설정 유지
- 게임 상태 정확성
- 마이그레이션
- 중복 보상 방지

## 56. Phase 9 완료 기준

다음 경험이 자연스럽게 작동해야 한다.

게임 실행
→ 첫 번째 블록 등장
→ 직관적인 조작
→ 정확한 건축 배치
→ 만족스러운 건축 효과
→ 다음 블록 공급
→ 공간 배치 전략
→ 도시 성장
→ 구조 위험 발견
→ 문제 해결
→ 도시 안정화
→ 새로운 발전 목표
→ 미션 완료
→ 만족스러운 결과
→ 다음 게임 도전

다음 상태를 목표로 한다.

- 건축 조작이 불편하지 않다.
- 건축물이 정확하게 배치된다.
- 불필요한 대기시간이 적다.
- 도시의 성장을 체감할 수 있다.
- 구조적 위험의 원인을 이해할 수 있다.
- 복잡한 기능이 기본 플레이를 방해하지 않는다.
- 여러 전략을 사용할 수 있다.
- 실패 이후 쉽게 다시 도전할 수 있다.
- 기존 게임 모드가 정상 작동한다.
- 싱글 플레이와 온라인의 데이터가 안전하게 분리된다.

정적인 UI 개선만으로 Phase 9가 완료되었다고 판단하지 않는다.

실제 게임 규칙과 조작 경험의 개선을 확인한다.
