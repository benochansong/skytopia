# 플레이 안내와 접근성

메뉴의 새 캠페인이 첫 진행 경로다. 캠페인 저장이 있으면 이어하기가 강조된다. 자유 건설 프리셋은 전폭 선택 상자로 표시하고 시작 버튼을 별도 행에 둔다. 구조·도시·수직·재난 실험실은 펼침 그룹에 모았으며 전체 메뉴는 화면 안에서 스크롤된다. 기존 별도 저장 슬롯은 유지한다.

처음 10분의 첫 건설 안내는 실제 배치·연결·전력·주거 상태를 보고 다음 조작을 설명한다. 안내를 접었다가 다시 볼 수 있으며 설정에서 끌 수 있다. 완료 보상이나 해금을 이 UI에 연결하지 않는다. 온라인에는 이 오프라인 안내를 표시하지 않는다.

설정 → 건축 조작에서 글자 크기100/115/130%, 높은 대비, 첫 건설 안내를 선택한다. 이전 모션·섬광·음량·키 반복·스냅 설정을 보존한다. 130%는 핵심 버튼·경고·설명 글자를 확대하며 전체 Canvas의 해상도나 게임 규칙을 바꾸지 않는다. 모든 작은 장식 문구를 같은 비율로 확대하는 기능은 아니다.

도시 운영 → 도시 현황에서 인구가 늘지 않는 원인과 초기 유예 시간을 확인한다. 전력·식량·정원·안정·행복·이재민·대피 상태를 구별한다. 이는 현재 조건 설명이며 미래 인구 보장이 아니다.

보통 조언은 우선순위 순 최대3개다. 코어·부양·국소 구조·심각한 전력·굶주림·활동 재난처럼 동시에 발생한 치명적 경고는 3개 제한에서 제외한다. 위험이 해소되면 사라지고, 일반 조언만 30초 숨길 수 있다. 위치가 있는 조언은 클릭하면 해당 구역으로 카메라를 이동한다. 재난 대응은 기존 재난 패널에서 수행한다.

주문·긴급 지원에서는 비용·대기·지원 횟수·잔액 조건·창고 여유 부족을 표시한다. 비활성 버튼의 이유도 별도 텍스트로 읽을 수 있다. 한국어와 영어는 같은 기능을 제공한다.

검증 화면은 docs/images/phase11-menu-large.png와 phase11-recovery.png이다. 스마트폰 UI, 전 화면의 스크린리더 낭독 순서와 모든 운영체제 배율은 검증하지 않았다.

첫 건설 안내는 왼쪽 정보 패널의 스크롤 흐름 안에 표시하며 카메라 버튼을 덮지 않는다. 기존 훈련 및 실험실에서는 중복 안내를 생략한다.
