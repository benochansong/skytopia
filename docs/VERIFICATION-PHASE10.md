## 실제 사진과 자산

맑은 낮·저녁·밤·설계도와 LOW–ULTRA 변경 전후, settings를 제외한 정지 도시 전체 상태가 동일함을 확인했다. 실제 다운로드 PNG는 2880×1800이며 최대 변 3840 제한을 검사했다. 캡처에 로고가 포함되고 HUD가 제외되는 것을 이미지를 열어 확인했다. 실제 게임의 시계·자원·재난을 사진 프리셋으로 변경하지 않는다.

자체 제작 ballast.gltf를 실제 GLTFLoader로 로드하고 같은 URL의 요청을 차단해 절차형 fallback과 도시 보존을 확인했다. 외부 파일을 읽지 못한다고 게임이 중단되지 않았다. 최종 모델 원점·타일 경계와 설정 테스트 4개 / 2파일을 2.89초에 추가 통과했다. 전체 실행 이후 추가한 모델 경계 1개를 포함하면 현재 전체 테스트는 256개이다.

## 성능 기준과 최종 측정

최종 원자료는 phase10-after.json이다. 반복 발전기·부양기 인스턴싱으로 draw calls는 83.5%, geometry는 86.7% 감소했다. 삼각형 수는 늘었고 소프트웨어 렌더러 평균 FPS는 이전보다 낮다. ## 회귀 범위

기존 건축·회전·카메라·저장·복구, 30개 캠페인 규칙, 수직 구조·층·교량·엘리베이터, 재난·방어·생존, 세계 탐험·운송·미션 완료, 실제 두 브라우저 대전·협동을 검사한다. 온라인 클라이언트 한쪽은 LOW, 다른 쪽은 HIGH에서도 동일 공급·서버 배치·결과를 확인한다.

## 확인한 수정과 한계

신규 브라우저 테스트가 도시 실험실 버튼의 보조 영문 이름을 빠뜨려 대기하다 실패했다. 접근성 이름을 맞춘 후 통과했다. 정지 발전기의 기본 발광, 낮에 빛나는 빈 주택, 삭제 타일의 나무, 일부 시설 위에 떠 있던 업그레이드 장식도 보완했다. 이미지 점검에서 깊은 앵커 암석이 지면 위로 나오던 문제를 발견해 암석 전체를 지면 아래로 옮겼다. 도로 표시는 가동 여부로 그룹을 나누지 않도록 수정했다.

정적 glTF 파이프라인·주요 절차형 모델을 구현했다. 전체 시설·선박·다리·지도 전면 재디자인, 볼륨 구름·블룸·SSAO·DOF와 신규 시네마틱은 미구현이다. 실제 GPU FPS, 장시간 최대 밀도/WAN 경기, 모든 사용자 접근성 기기와 미학적 만족도는 미검증이다. 기존 audit 항목과 Node SQLite 실험 경고, Three 대형 청크 권고는 남아 있다. 공개 배포·병합·DNS 변경은 하지 않았다.
